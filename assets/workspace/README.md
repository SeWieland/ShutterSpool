# Workspace assets

The [ApertureBackground component](../../src/ShutterSpool.Web/app/components/ApertureBackground.vue) contains the workspace's authored SVG aperture geometry.
Its blades stay fixed while only the outer rim's containing layer rotates; reduced motion keeps it static.

[Manrope](../../src/ShutterSpool.Web/public/Manrope.ttf), variable weights 200–800, comes from the [Google Fonts source repository](https://github.com/google/fonts/tree/main/ofl/manrope).
It is unmodified and served locally. The [SIL Open Font License and copyright notices](../../src/ShutterSpool.Web/public/Manrope-OFL.txt) ship with it.
The [icon set](../icons/README.md) contains the shutter brand artwork and supporting variants.
